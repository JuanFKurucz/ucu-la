Dónde estamos

v0.3 busca en tus documentos, cita, se abstiene y recuerda por hilo. Pero solo sabe una cosa. Ante algo reciente, que no está en tus documentos, dice NO ENCONTRADO; una cuenta la hace de cabeza, y los LLM son malos con números precisos. Hoy le damos herramientas y lo dejamos elegir: un agente.

2. Workflow o agente

  • Workflow: vos decidís los pasos (v0.2). Predecible, barato, fácil de medir.
  • Agente: el modelo elige herramienta, cuántas veces y en qué orden. Flexible, más caro, más difícil de medir.
  • Empezá por lo más simple que funcione (Anthropic — Building effective agents, lectura 1). El proyecto pide agente: medimos si elige bien.
  • AgentExecutor es la forma vieja: desde LangChain 1.0 es create_agent (guía de migración); importarlo da ImportError: cannot import name 'AgentExecutor'.

3. Cómo funciona un agente (el ciclo ReAct)

  • Razonar → actuar → observar, hasta poder responder (Yao y otros, 2022; Prompting Guide — ReAct).
  • El modelo pide un tool call («calcular con porcentaje_cambio, a=80, b=100»); tu programa lo ejecuta (el modelo no ejecuta nada) y le devuelve «25».

  • Ayuda porque consultar una fuente entre paso y paso frena el error que arrastra el razonar solo.

  • Así se vio de verdad (uv run python -m ejemplos.clase6 ciclo; el 6 es el módulo M6; Gemini 3.5 Flash-Lite): «¿cuántas filas tiene la tabla que compara checkpointer y store? Multiplicá por 3».

  • Pidió buscar_documentos, leyó la tabla, pidió calcular(5 × 3) y respondió 15: dos herramientas, tres llamadas al modelo.
  • La tabla tiene 5 filas de comparación y una sexta de enlaces («Full guide»): «5» vale si se cuentan solo las de comparación, y así lo espera la suite.

4. Las herramientas por dentro

En herramientas.py, cada herramienta es una función con la etiqueta @tool:

@tool
def calcular(operacion: Literal["suma", "resta", "multiplicacion", "division", "porcentaje_cambio"],
             a: float, b: float) -> str:
    """Hace una cuenta con dos números. porcentaje_cambio = (b - a) / a * 100. Usar para cualquier cuenta."""

El modelo ve solo nombre, datos y su tipo (Literal[...]: solo esos valores) y descripción (LangChain — Tools).

  • Así le llega de verdad (recortado: en la salida real todo va adentro de "function", los datos van dentro de "properties" y "required" los lista a los tres; Python lo imprime con comillas simples).
  • Para verlo entero, parado en la carpeta del proyecto: uv run python -c "from herramientas import calcular; from langchain_core.utils.function_calling import convert_to_openai_tool as c; print(c(calcular))"
{"name": "calcular",
 "description": "Hace una cuenta con dos números. porcentaje_cambio = … Usar para cualquier cuenta.",
 "parameters": {"operacion": {"enum": ["suma", "resta", "multiplicacion", "division", "porcentaje_cambio"]},
                "a": {"type": "number"}, "b": {"type": "number"}}}
  • La descripción dice qué hace, cuándo usarla y cuándo no; nombres claros (consulta, no x). Cómo escribirlas: Anthropic — Writing effective tools for agents.
  • Medido (… clase6 descripcion, gpt-5.4-nano, 17/10 y 19/10):
  • Descripción o SISTEMA claros: 12 de 12. Vagos: 11 y 12 de 12 (azar: con preguntas fáciles no se nota).

Cuando la web falla

DuckDuckGo limita si muchos buscan desde la misma red. La línea web de config.toml:

  • "real": busca de verdad; devuelve pedazos cortos y a veces raros (el 18/10, sobre LangGraph: «Jan 2, 2016», que no existía, y ninguna versión). Mirá qué le llegó antes de creerle.
  • "grabada": devuelve siempre los mismos tres renglones (de PyPI y GitHub, sin números de versión), pregunte lo que pregunte. Sirve para medir qué herramienta elige, no la respuesta. Declaralo.
  • "caida" (sin tilde): simula la caída, para ver si avisa o inventa.

5. Límites en código, no en el prompt

Un agente puede dar vueltas, y cada vuelta cuesta. En v04_agente.py:

MAX_LLAMADAS_MODELO = 6        # perillas, arriba del archivo
MAX_LLAMADAS_HERRAMIENTAS = 5
# más abajo, al crear el agente:
middleware=[ModelCallLimitMiddleware(run_limit=MAX_LLAMADAS_MODELO),
            ToolCallLimitMiddleware(run_limit=MAX_LLAMADAS_HERRAMIENTAS)]
  • run_limit cuenta por pregunta; thread_limit, por conversación (middleware de LangChain).
  • 6 llamadas al modelo: termina. Más de 5 pedidos de herramientas: se rechazan y responde con lo que tiene.
  • Lo que no puede fallar va en código; el prompt es una guía.

Sin gastar, los topes se prueban con un modelo falso que pide herramientas sin parar: uv run pytest tests/test_agente_ciclo.py (6 passed).

En el grafo real del agente, los topes son cajas del ciclo: corren antes y después de cada llamada al modelo.

SyntaxError: invalid syntax. Perhaps you forgot a comma? al cambiar SISTEMA (o unterminated string literal, o '(' was never closed) Cada renglón del texto va entre comillas ("…"), y Python los junta. Un renglón sin comillas da ese error, aunque no falte ninguna coma; uno con la comilla de cierre borrada, unterminated string literal (en el renglón que dice); sin el ) del final, '(' was never closed. Dejá un espacio antes de la comilla de cierre, para que las palabras no se peguen.

La suite dice «Ojo: N de M preguntas dieron ERROR» y en el CSV la respuesta es «ERROR: GoogleRateLimitError: …» (u otro …RateLimitError) Es un 429: una suite con agente gasta decenas de pedidos (v0.4, unos 32). Esperá un minuto y volvé a correr: si sigue el 429, se terminó la cuota del día (el CSV recorta el error y no llega a mostrar «PerDay»): esperá a mañana o cambiá de modelo en config.toml (guía 2). Esas filas no miden tu sistema.
«MAX_LLAMADAS_MODELO = …: va un entero de 1 para arriba, sin comillas» (o MAX_LLAMADAS_HERRAMIENTAS, o RECORTE en herramientas.py) Pusiste 0, un número con punto (2.5, 1.000) o el número entre comillas ("6"). Va un entero, de 1 para arriba: MAX_LLAMADAS_MODELO = 6, RECORTE = 600.
«No llegué a una respuesta: se alcanzó el tope de llamadas al modelo.», o la respuesta habla de «Tool call limit exceeded» (el aviso, en inglés, que recibe el modelo al pasar MAX_LLAMADAS_HERRAMIENTAS) Llegó a un tope: el límite funcionó. Mirá qué herramientas pedía y por qué tantas.
Un error del proveedor: «429…», «503…», «500 o 504», «Sin conexión…», «404…» o «sin saldo» Son los mismos de la clase 2 y se arreglan igual: «Si te trabás» de la guía 2, una fila por error.
