Antes de empezar: la terminal en 2 minutos

La terminal es una ventana donde escribís órdenes y apretás Enter.

  • Windows: tecla Windows → escribí PowerShell → Enter.
  • Mac: Cmd + Espacio → escribí Terminal → Enter.

Tres órdenes que vas a usar:

Orden Qué hace
cd nombre-de-carpeta Entra a una carpeta. cd .. vuelve una atrás.
ls (Mac) o dir (Windows) Muestra lo que hay en la carpeta donde estás.
Flecha arriba Repite la última orden.

Si algo no anda, copiá el mensaje completo y mostralo. Los mensajes de error casi siempre dicen qué pasó.

3 reglas

  1. La clave no sale de .env: ni al código, ni al chat de un asistente, ni a una captura.
  2. Datos personales no van a la API. Los documentos del proyecto son públicos o autorizados.
  3. Cuidá el saldo y la cuota: config.toml limita la salida a 300 tokens; no lo subas sin motivo. Con la clave gratis de Gemini tenés 500 pedidos por día por modelo (lo agotamos el 17/10): una corrida de la suite con agente gasta decenas. Corré la suite cuando cambiaste algo, no «por las dudas».

¿Falló?

Mensaje Qué hacer
uv no se reconoce Cerrá y volvé a abrir la terminal. Si sigue, reinstalá.
No such file o no se encuentra check_setup.py No estás en la carpeta del proyecto: usá cd.
ModuleNotFoundError: No module named 'httpx' (u otro nombre) Te faltó uv run adelante: uv run python check_setup.py. Con python solo corre el Python de tu computadora, sin las librerías del proyecto.
.env ignorado por git: NO No subas nada a GitHub (no hagas commit) y avisá.
.env ignorado por git: no se pudo comprobar… Si dice «no es un repo git», bajaste el ZIP: cloná el repo con GitHub Desktop (paso 2) y corré de nuevo. Si dice «la terminal no encuentra git», es normal con GitHub Desktop: mirá que .env no aparezca en su pestaña Changes.
Error de clave («API key not valid»: en Gemini es un 400; en otros proveedores, 401) o «Falta la clave» La clave va después del =, en el mismo renglón (GOOGLE_API_KEY= y la clave pegada), sin espacios en el medio; las comillas no molestan. Seguí con --fixture y mandá el error exacto al foro «Consultas» del aula virtual. Se resuelve antes de la clase 2.
Error de red o timeout Seguí con --fixture y probá de nuevo en casa.
429 RESOURCE_EXHAUSTED que dice «PerDay» (o «per day») Se terminó la cuota gratis del día: no reintentes. Esperá al otro día o cambiá de modelo en config.toml.
